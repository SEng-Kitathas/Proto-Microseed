### 4. MS1933 scale warning — donor direction survives, exact framing narrowed
MS1933 used a synthetic fixture of 8 branches × depth 3 = 24 capabilities against the named `GLOBAL_AUTHORIZATION_EPOCH_BASELINE`.

Verified measurements:
- coordination/root drift: 3/24 local vs 24/24 baseline = 8× smaller stale/recheck set;
- leaf drift: 1/24 vs 24/24 = 24× smaller;
- shared upstream drift: 24/24 vs 24/24 = no locality advantage.

MS1933 explicitly did **not** claim superiority over every centralized architecture.

Critically, MS1933 measured stale/recheck set size. It did not directly measure:
- requalification wall cost;
- evidence reacquisition cost;
- scheduler/tick closure cost;
- cyclic dependency qualification semantics.

### 5. Read-only large-N probe — OBSERVED, not seal evidence
A non-mutating synthetic probe replayed the CapabilityRegistry locality shape at 24, 120, 300, 1,000, 1,500, and 3,000 branch-local capabilities.

Observed:
- branch-local stale count remained proportional to branch depth rather than total graph size;
- leaf invalidation remained one node;
- a truly shared root still invalidated the full dependent set;
- simple invalidation traversal stayed small in this synthetic registry probe.

Therefore the current evidence does **not** show a simple large-N stale-set explosion.

However, the probe also showed that a capability dependency cycle `A -> C -> B -> A` is registrable. Invalidation terminates because the registry uses a visited set, but this does not establish lawful cyclic qualification/currentness closure.

Formal campaign required:
`LARGE_N_INVALIDATION_LOCALITY != LARGE_N_QUALIFICATION_CLOSURE`.

The formal campaign must measure actual qualification/requalification work, currentness closure, restart/replay behavior, and cyclic/shared dependency cases rather than merely enlarging MS1933's stale-count fixture.
