# MS1940 — Opaque Signaling by Existing Composition

Date: 2026-08-29 ET
Status: bounded integration experiment / no production mechanism added
Parent public head: `3473834da0ce1bbc0db16a35f4b9b8e2fa551ee2`

## Question
Can the existing Microseed architecture support a **signal** in the narrow operational sense:

> emit an opaque token through an already-qualified effect capability, an independently changing opaque counterparty consumes that token under a currently qualified coordination relation, and externally observed joint behavior changes,

without granting reference, meaning, language, semantic intention, promise, persistent other-agent identity, truth, or new execution authority?

Prewritten scars:
- `SIGNAL != REFERENCE`;
- `TOKEN_EMITTED != TOKEN_MEANS`.

## Why this is the next discriminator
The post-MS1939 direct organism frontier was signaling/reference. Reference remained blocked behind object/identity/semantic preconditions. Signaling is a narrower property and can be pressure-tested using mechanisms that already exist:
- `OperationalCounterpartyContract`;
- `OperationalCoordinationContract`;
- capability dependencies on counterparty/coordination epochs;
- bounded EFFECT execution;
- external observation-basis outcome closure;
- counterfactual rehearsal;
- referent nomination with identity authority NONE.

Under the adopted RAHL SOP, composition is tested before adding a new subsystem.

## Assistance ancestry / nonclaim boundary
The MS1940 fixture supplies:
- the constitutional value variable and viable interval;
- opaque action/signal token `T0`;
- the counterparty relation/currentness contract;
- the token-contingent coordination contract;
- the external observation channel;
- rehearsal transition evidence.

Therefore MS1940 does **not** establish:
- endogenous token invention;
- endogenous convention discovery;
- self-constructed semantics;
- object/reference binding;
- mutual semantic intention;
- persistent other-agent identity;
- language.

The earned question is only whether the existing authority/currentness/action/outcome architecture can carry an opaque signal relation lawfully once the required operational contracts are supplied.

## Fixture
The signal capability `SIG-T0`:
- has `Authority.EFFECT`;
- emits raw token `T0` in the synthetic external world;
- is bound to counterparty `CP@0` and coordination relation `R@0`;
- carries no semantic message/reference authority.

The external counterparty observation capability returns:
- `CP-NOACK` before the expected token has been emitted;
- `CP-ACK` after token `T0` is emitted when the current external convention expects `T0`.

The outcome closes only through the ordinary bounded observation-basis path.

## Reality-disagreement hostile
A fresh world kept the supplied coordination contract/currentness apparently live but changed the external convention to expect `T1`.

Microseed still emitted `T0` because the current model/rehearsal predicted the old relation. External observation then returned `CP-NOACK`.

Required behavior survived:
- the observed outcome was preserved;
- the action prediction commitment became `NO`;
- regulatory pressure remained unresolved;
- the organism did not fabricate a new meaning/reference;
- the coordination relation did not autonomously stale itself merely because a prediction failed.

This preserves the boundary between:
- observation of failed behavior;
- inference that a supplied coordination contract is no longer current;
- semantic interpretation of the token.

Those are not collapsed.

## Coordination/counterparty currentness hostiles
After proposal formation:
- explicit `change_operational_coordination("R", reason=...)` stales the coordination-bound signal capability and causes action-intent nomination to abstain;
- explicit `change_operational_counterparty("CP", reason=...)` invalidates the dependent coordination and signal route;
- changing coordination requires an explicit `reason` argument.

The signal cannot silently outlive its current operational relation.

## Earned result
`OPAQUE_SIGNALING_BY_EXISTING_COMPOSITION` is supported under the supplied synthetic fixture.

More precise statement:

> A currently qualified opaque EFFECT token can participate in a counterparty-contingent behavior-changing loop using the existing Microseed counterparty/coordination/currentness/action/outcome machinery, while reference/meaning/identity/intention/language authority remains absent.

This is an integration property, not a novelty claim and not a semantic-language capability claim.
