# MS2005 — BOUNDED REFERENT PROBE RECONSTRUCTION

## Question
Does endogenous referent information seeking require a new durable bucket→class-set store, or can the missing alternative content be reconstructed from already-owned persisted operational referent-signature witnesses?

## Composition-first hypothesis
The existing bucket is a deterministic digest of the fixed opaque coordinate plus a sorted set of operational referent signature-class hashes. Individual signature witnesses already persist both class hash and opaque action-response rows. Therefore a bounded exhaustive subset search over a saturated evidence window may reconstruct historical class-set content without a new referent registry or manager.

## Evidence law
- Search must be explicitly bounded.
- If the evidence scan is not saturated, absence is UNKNOWN rather than false absence.
- Multiple class-set preimages remain AMBIGUOUS.
- Probe informativeness compares only predicted opaque response multisets, not class IDs or semantic labels.
- Multiple informative probes remain AMBIGUOUS; iteration order grants no selection authority.
- No numerical identity, semantic reference, truth, selection, or execution authority is gained.

## Hostile discriminator
Using the existing MS2003 contexts A/B, reconstruction occurs after closing and reopening Microseed so only durable evidence remains. The recovered alternatives must exactly regenerate their prior bucket hashes. Probe comparison must reject false information from class identity: P0/P1/P3 have the same opaque response multiset in both alternatives, while P2 and P4 differ. The correct result is therefore `CURRENT_REFERENT_PROBE_AMBIGUOUS`, not an arbitrarily chosen probe.

## Promotion boundary
A PASS earns only: existing persisted signature evidence is sufficient to reconstruct bounded historical class-set alternatives and derive an inert set of informative opaque probes. It does not earn probe choice, execution, general active learning, identity, or semantic reference.

## Second discriminator — unique availability without sequence assistance
A second raw-trace fixture removes the ambiguity intentionally without supplying the answer. Two persisted class-set alternatives have identical opaque response multisets for P0/P1/P3/P4 and differ only on P2. After restart, the same bounded reconstruction must derive `CURRENT_UNIQUE_INFORMATIVE_REFERENT_PROBE` with P2. This earns only inert availability: selection/execution authority remain NONE.
