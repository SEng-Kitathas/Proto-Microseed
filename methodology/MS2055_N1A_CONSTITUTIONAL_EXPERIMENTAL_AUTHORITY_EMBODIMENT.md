## Production embodiment
N1A is composed from existing owners plus one narrow carrier/persistence distinction:
1. current qualified EFFECT capability;
2. exact capability epoch and content signature;
3. exact query obligation and operational scope;
4. exact current opaque control-state witness;
5. organism-owned complete current constitutional value frame;
6. refusal if a current consequence model/value-bound effect already exists;
7. exactly one eligible unmodeled action, else abstain;
8. exact `ConstitutionalExperimentalWarrant` with no selector/truth/safety/semantic authority;
9. durable subject-level reservation before EFFECT using atomic `StateStore.set_if_absent`;
10. effect-time re-derivation of the exact nominated premises;
11. actual outcome returns through the existing bounded action/outcome surface and records the complete issue-time value frame;
12. actual observed consequences become evidence, while retrospective safety authority remains NONE.

The one-shot subject is bound to capability ID + epoch + content signature + obligation + operational scope. It intentionally excludes state so a state transition or crash cannot manufacture another “first” exposure for the same qualified action epoch.

## Moral-compass interpretation
The complete current constitutional value frame is mandatory. Caller-selected value subsets cannot define the moral frame. If a consequence is already currently modeled, N1A refuses the action rather than laundering known positive or negative consequences into residual unknownness.

This does not invent a generic prohibition ontology. Existing structured capability qualification, value/regulatory consequence evidence, currentness, scope, and action authority remain the owners.

## Outcome sovereignty
N1A carries no predicted consequence. After EFFECT, the external observation owns the result. A harmful actual outcome is recorded as harmful evidence; it does not retroactively become “safe because the experiment was authorized.”
