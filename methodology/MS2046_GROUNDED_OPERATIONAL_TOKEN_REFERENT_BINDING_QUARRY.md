# MS2046 — Grounded Operational Token→Referent Binding Quarry

## Goal
Pressure the technical **reference-admission** seam without opening the language gate and without treating fluent/readable token surfaces as meaning.

The narrow question is:

> Can repeated actual use of one already-current opaque signal capability, followed by current raw observation of a counterparty-contingent referent-localized effect, support a content-bound operational token→referent binding candidate that survives sensor permutation and fails closed under aliasing, ambiguity, and currentness drift?

## Governing ceilings
Preserve exactly:
- `SIGNAL != REFERENCE`;
- `TOKEN_EMITTED != TOKEN_MEANS`;
- `LEARNED_ASSOCIATION != REFERENCE_AUTHORITY`;
- `OPERATIONAL_REFERENT_SIGNATURE != NUMERICAL_OBJECT_IDENTITY`;
- `UTTERANCE_PRODUCED != REFERENT_BOUND`;
- `LANGUAGE_QUALITY != EPISTEMIC_AUTHORITY`;
- `FLUENCY != CURRENT_PREMISE`.

The quarry may earn a **reference-admission candidate**, never semantic-reference authority by itself.

## Existing mechanisms reused
- current qualified EFFECT capability for an opaque signal token;
- current counterparty/coordination contracts and transitive currentness;
- actual physical handler effect;
- raw observation-only sensor capability;
- existing boundary-coherent operational referent partitioning;
- existing affordance-relative referent signatures;
- exact current capability/coordination signatures and epochs;
- independent held-out use episodes for qualification pressure.

No token dictionary, semantic object registry, language model, referent-ID manager, or meaning store is introduced.

## Synthetic external world
Two evaluator-only latent referents, two channels each.

Current owned calibration effects `FX-P` and `FX-Q` differentiate the two operational partitions. These handles are opaque to the binding derivation.

Opaque signal capability `SIG-X` causes the external counterparty relation to perturb one latent referent under the current convention. The organism observes only raw channels before/after the signal. The evaluator-only latent source label is never supplied to the candidate derivation.

Training and holdout use different sensor permutations and affine renderings.

## Candidate derivation
A training episode is admissible only when:
1. the signal capability is current at its exact epoch/signature;
2. the coordination relation is current at its exact epoch/signature;
3. the pre-signal raw sensor surface admits a current operational referent partition/signature set under the current opaque calibration handles;
4. the post-signal raw change localizes to exactly one already-nominated operational referent group;
5. the changed group's affordance-relative signature is exact and current;
6. every admitted training episode resolves to the same operational signature.

The proposal is then pressure-tested on disjoint holdout episodes under a different sensor layout. Every holdout must resolve to the same operational signature.

Resulting candidate carries exact source episode hashes and currentness descriptors and has:
- `binding_status = QUALIFIED_OPERATIONAL_TOKEN_REFERENT_BINDING_CANDIDATE`;
- `semantic_reference_authority = NONE`;
- `token_meaning_authority = NONE`;
- `numerical_identity_authority = NONE`;
- `truth_authority = NONE`;
- `execution_authority = NONE`.

## Hostiles
1. **Sensor permutation / appearance change** — binding signature remains stable.
2. **Ambiguous signal effect** — signal changes both distinct referents -> no unique binding candidate.
3. **Referent alias symmetry** — calibration structure collapses both referents -> no binding candidate.
4. **Signal capability drift** — old candidate becomes stale.
5. **Coordination drift** — old candidate becomes stale.
6. **Perfect-copy replacement** — operational signature may remain the same, but numerical identity remains NONE.
7. **Fluent/readable token with no grounded use history** — no candidate merely because the token string is human-readable.
8. **Counterparty convention reversal** — old binding fails holdout/current-use checks; no automatic new meaning is invented.

## Expected technical result
If positive:

`REPEATED_CURRENT_SIGNAL_USE_PLUS_REFERENT_LOCALIZED_COUNTERPARTY_EFFECT_CAN_SUPPORT_A_QUALIFIED_OPERATIONAL_TOKEN_REFERENT_BINDING_CANDIDATE_WITHOUT_SEMANTIC_REFERENCE_AUTHORITY`.

and:

`GROUNDING_CANDIDATE != LANGUAGE_GATE_ADMISSION`.

## Nonclaims
No language admission, semantic meaning, compositional syntax, truth authority, numerical object identity, persistent other-agent identity, or autonomous convention creation.

`MS2046_HARNESS_CAPABILITY_CURRENTNESS_API_SHAPE_MISMATCH__NO_SCIENTIFIC_VERDICT`.

The candidate derivation itself had already reached its positive path, but no campaign verdict is promoted from a run that failed before all currentness/hostile checks. Repair shall compare `epochs[id]` explicitly in addition to the one-argument `is_current(id)` API.
