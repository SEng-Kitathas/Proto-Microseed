# MS2020 — DEFICIT-OWNED POST-PROBE REHEARSAL RE-ENTRY

## Goal
Remove the remaining caller relay of projection binding ID and resolved bucket ID between referent probe closure and downstream rehearsal.

## Composition
The completed referent deficit already owns an exact projection anchor and qualified-routing hypothesis digest. After `REVISIT_REQUIRED`, Microseed scans only current matching routing bindings, re-derives the current authenticated raw/action prefix, requires one resolved survivor, and passes that internally derived bucket into the existing counterfactual rehearsal owner.

## Gates
- deficit must be current `REVISIT_REQUIRED` and carry referent-derived ancestry;
- exactly one projection anchor;
- exactly one current routing binding with the deficit's exact hypothesis digest and one current resolved survivor;
- rehearsal horizon/channel must exactly match the current binding;
- caller supplies neither binding ID nor bucket ID.

## Authority
Resolved bucket remains query-local operational context. No identity, semantic reference, truth, selection, execution, planner, or model-switch authority is added.
