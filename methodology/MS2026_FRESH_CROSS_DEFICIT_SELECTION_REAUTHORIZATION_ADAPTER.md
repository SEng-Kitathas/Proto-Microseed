# MS2026 — FRESH CROSS-DEFICIT SELECTION REAUTHORIZATION ADAPTER

## Goal
Prove the MS2025 stale-selection violation can be repaired compositionally before modifying runtime owners.

## Adapter law
For an intent whose selected deficit was materialized from strict same-value cross-deficit selection:
1. Re-enumerate the current owned referent epistemic opportunities.
2. Re-derive current same-value strict regulatory dominance.
3. Re-derive the bounded cross-deficit selection commitment.
4. Require one current YES selection whose selected deficit id and probe id exactly match the nominated intent's selected deficit/probe.
5. Only then delegate to ordinary `execute_bounded_action`, which still owns local epistemic/capability/currentness reauthorization and EFFECT invocation.

The adapter itself grants no execution authority.

## Hostiles
- stable asymmetric surface: P2 remains uniquely dominant -> ordinary executor may execute P2 once;
- post-nomination new strong P4 competitor: fresh selection becomes tie/UNKNOWN -> adapter returns NO_EXECUTION and must not call ordinary EFFECT handler;
- caller cannot supply the competitor set, winner, or selection result.

## Promotion boundary
A PASS proves no scheduler or persistent opportunity registry is needed to close MS2025. It does not yet prove the reauthorization belongs in the runtime; promotion requires a separate owner/ancestry campaign.
