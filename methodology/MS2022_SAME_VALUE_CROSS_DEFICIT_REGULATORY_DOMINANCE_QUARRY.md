# MS2022 — SAME-VALUE CROSS-DEFICIT REGULATORY DOMINANCE QUARRY

## Question
Is the MS2021 P2/P4 blocker a total absence of comparison structure, or can existing rehearsal + regulatory-value owners derive a narrow strict partial order when two independently decision-bearing deficits are bound to the exact same current value coordinate?

## Constraints
- no weighted utility;
- no cross-value comparison;
- no scheduler / priority manager / pick-first rule;
- no caller-supplied importance labels;
- compare only opportunities that are individually current, information-bearing, step-licensed, and anchored to the same exact `(value_id, value_epoch)` with one current value observation;
- derive consequence from existing one-step counterfactual rehearsal under each live alternative;
- use only worst residual regulatory pressure after the alternative-conditioned best current action;
- strict dominance exists only when one opportunity has strictly lower worst residual pressure than the other; equality remains ambiguity.

## Hostiles
1. Replay the symmetric MS2021 P2/P4 fixture. Both opportunities should have identical worst residual pressure and therefore no dominance.
2. Build an otherwise-equivalent second P4 pressure whose alternative-conditioned best C/D action only partially relieves the same current V pressure. P2's opportunity should then have strictly lower worst residual pressure than P4.
3. The quarry itself grants no selection or execution authority. It asks only whether the already-owned evidence contains a lawful strict comparison coordinate.

## Interpretation
If the asymmetric case derives strict dominance while the symmetric case remains unresolved, the blocker narrows from `NO_CROSS_DEFICIT_COMPARISON_CONTENT` to `MISSING_WIRING_FOR_STRICT_SAME_VALUE_REGULATORY_DOMINANCE`. If not, stop; do not invent scalar priority.
