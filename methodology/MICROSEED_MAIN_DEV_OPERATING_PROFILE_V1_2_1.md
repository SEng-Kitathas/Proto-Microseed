## Additive method promotion

The old “causal entropy” donor signal is decomposed rather than imported wholesale:

```text
OBSERVATIONAL / NUISANCE ENTROPY
!=
CAUSAL AMBIGUITY / IDENTIFIABILITY
!=
CURRENT ACCESS TO A DISCRIMINATING INTERVENTION
```

Campaigns should distinguish four epistemic states when load-bearing:

- **A ESTIMATION_LIMITED** — identifiable, but current evidence quality/budget is insufficient.
- **B PASSIVELY_AMBIGUOUS** — passive evidence is insufficient; current phenotype has an active discriminator.
- **C ACTION_LIMITED** — a discriminator exists in the bounded world, but current phenotype lacks it; preserve `UNKNOWN_NOW` and surface missing discriminating capability.
- **D STRUCTURALLY_NON_IDENTIFIABLE** — no bounded evidence/intervention available to the phenotype separates alternatives; hard ceiling for the tested envelope.

Locks:

```text
AMBIGUOUS_UNDER_CURRENT_EVIDENCE != FUNDAMENTALLY_NON_IDENTIFIABLE
DISCRIMINATING_INTERVENTION_EXISTS_IN_WORLD != CURRENT_PHENOTYPE_HAS_ACCESS
ACTIVE_PROBE_REDUCES_UNCERTAINTY != ACTIVE_PROBE_CONFERS_TRUTH_AUTHORITY
ACTION_LIMITED_UNKNOWN != STRUCTURAL_NONIDENTIFIABILITY
```

## Correspondence attacks remain a separate question

Within-world difficulty is not the same as cross-world invariance. Where relevant, campaigns should pair:

```text
same causal law / radically changed surface
similar surface / changed causal law
```

These test what the mechanism tracks, not how noisy one world is.

## Currentness pressure

When applicable, distinguish drift of nuisance, causal law, action repertoire, learned relation, and discriminator availability. A disappeared discriminator can reduce current knowability without retroactively changing historical evidence.

## Topology guard

Learned topology may guide proposal search. It may not become a closed ontology of what can exist. Proposal systems must retain a route for residual-driven or higher-order structure outside current topology.
