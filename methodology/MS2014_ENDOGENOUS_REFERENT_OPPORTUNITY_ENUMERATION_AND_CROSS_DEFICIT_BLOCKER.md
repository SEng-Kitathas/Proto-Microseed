# MS2014 — ENDOGENOUS REFERENT OPPORTUNITY ENUMERATION AND CROSS-DEFICIT BLOCKER

## Question
Can current referent epistemic pressure be derived before any durable deficit exists, without caller-supplied binding/deficit ids; and what happens when two independently qualified current referent surfaces demand different informative probes?

## Composition
For each current projection-conditioned binding on the fixed operational-referent class-set coordinate:
1. derive the current owned partial referent ambiguity from raw/action ancestry;
2. require exactly one informative opaque probe;
3. project only current qualified routing relations into decision alternatives;
4. derive the exact common current VALUE epoch from those relations;
5. construct an **ephemeral** ACTION_LIMITED deficit identity from content only;
6. construct an **ephemeral** one-step generated candidate/trial for the unique probe;
7. reuse grounded feasibility, regulatory decision-bearing priority, program information, and step commitment.

Nothing is registered or executed during enumeration.

## Hostiles
- one current qualified A/B surface -> exactly one admissible P2 opportunity;
- content-equivalent duplicate binding -> must not create a second opportunity after content deduplication;
- add an independent A/D surface that matches current P0/P1 but differs only under P4, with a separately decision-bearing C/D downstream action split -> P2 and P4 opportunities coexist.

## Blocker criterion
Existing `arbitrate_endogenous_epistemic_trial_candidates` arbitrates program candidates **inside one already-owned deficit**. It accepts one `deficit_id` and one decision context. No existing owner grants authority to rank different current deficits/opportunities with incomparable content partitions. If P2 and P4 opportunities both survive and neither is a duplicate/same-action composition, choosing one would require a new cross-deficit priority distinction. The campaign SHALL stop rather than reintroduce a generic scheduler or pick-first manager.
