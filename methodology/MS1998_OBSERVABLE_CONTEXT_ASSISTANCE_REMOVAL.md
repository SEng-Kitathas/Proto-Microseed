## Why a narrow core bridge was justified
Before mutation, the published tree had two already-earned owners:
- `resolve_current_raw_projection_conditioned_relation(...)` could derive a current partition-scoped relation and projection bucket from exactly one current bounded raw receipt;
- `nominate_counterfactual_rehearsal(...)` could consume an already-qualified routing binding **if the caller supplied the bucket**.

The missing behavior was therefore not a missing planner. It was an API seam:
`OWNED_BUCKET_DERIVABLE` but `REHEARSAL_REENTRY_STILL_CALLER_BUCKET_DEPENDENT`.

MS1998 adds one narrow composition method to `Microseed`:

`nominate_current_raw_projection_conditioned_rehearsal(...)`

The bridge:
- accepts no projection bucket;
- accepts no routed relation ID;
- introduces no persistent registry/state;
- requires the existing qualified routing binding to be current;
- derives current routing through every eligible option using the existing current-raw resolver;
- consumes the routing binding's already-qualified horizon rather than borrowing rehearsal search depth as authority;
- requires every eligible option to resolve to one identical current bucket;
- fails closed on missing, stale, duplicate, ambiguous, or inconsistent evidence;
- then calls the existing rehearsal owner with that internally derived bucket.

Authority remains NONE for truth, semantic regime, model switch, self-qualification, policy selection, and execution.

## Layer B — remove evaluator-mode-conditioned training guidance
### World
MS1998 extends the MS1997 three-locus external world:
- actions: `K-17 -> M-23 -> R-41`;
- common visible control path: `s0 -> s1 -> s2`;
- latent external terminal alternatives: `u` versus `v`;
- opposite regulatory effects: +1 versus -1;
- both trajectories end at regulatory value 0.

The world additionally exposes two bounded raw coordinates through the already-current OBSERVATION_ONLY channel:
- coordinate 0: opaque scalar `0` when the **currently observed regulatory value** is below zero, else `1`;
- coordinate 1: constant nuisance scalar `x`.

This is current organism-visible observation. It is not the evaluator P/N label and receives no semantic coordinate authority.

### Training guidance
The remaining equipped one-step guidance is deliberately weaker than MS1997:
- the assistance function receives **no world object and no evaluator mode**;
- it reads only the Microseed's current opaque control state and latest observed regulatory value;
- below the viable interval it predicts +1 regulatory effect;
- above the viable interval it predicts -1 regulatory effect;
- the common `s0 -> s1` and `s1 -> s2` transitions may be supplied;
- terminal identity is supplied only as `terminal-opaque-unpredicted`, never `u` or `v`;
- all current opaque action options remain present; no preferred action is passed.

A wrong terminal prediction does not block evidence ingress. Ordinary outcome recording preserves the actual external outcome and marks the prediction commitment NO. Thus actual consequences remain sovereign.

### Historical relation phase
Twelve lived historical-mode episodes produce ordinary authenticated executions/outcomes.

The existing action-outcome learner nominates exactly one predictive candidate per action from actual outcome history. Later, disjoint lived episodes supply external qualification evidence derived from observed outcomes. The resulting historical relations predict +1 effects and the historical terminal.

### Drift and replacement phase
Reality is switched to the opposite latent external dynamics, but the training assistance still sees only current organism-visible state/value.

Sixteen opposite-mode lived episodes produce post-admission failures of the historical relations.

For each action:
- existing bounded currentness assessment produces a durable `DRIFT_WITNESS`;
- existing replacement nomination consumes only that witness's drift-evidence rows;
- one replacement candidate is derived;
- later disjoint lived outcomes qualify the replacement relation.

The historical relation remains globally stale. The replacement relation is current. No drift cause, semantic regime, or model-switch authority is created.

### Owned raw projection
Before each ordinary action, the already-current observation channel records one bounded raw receipt bound to the exact current control-state evidence.

The EFFECT and OBSERVATION channels are explicitly bound to the already-existing operational frame; no new frame or capability is added.

`derive_admitted_projection_samples_from_owned_raw_observations()` joins those raw receipts to authenticated action outcomes. The direct boundary produced **180 owned raw projection samples** before the later qualification/handoff phases.

Projection search is exhaustive under an explicit two-subset-evaluation budget with `max_subset=1` over the two raw coordinates. Exactly one candidate survives: a single-coordinate discriminator with validation accuracy 1.0. No caller coordinate is selected.

External projection qualification remains external by constitution.

### Projection-conditioned relation routing
The routing proposal is built from already-admitted content:
- the admitted projection's opaque endpoint predictions;
- the historical qualified relation endpoints;
- the replacement qualified relation endpoints.

The historical-context bucket routes to the globally stale historical relations only within the externally qualified partition-scoped binding.
The opposite bucket routes to the current replacement relations.

This does **not** globally reactivate the historical relations.

External routing qualification uses later disjoint lived outcomes. The binding grants no truth, semantic-regime, model-switch, self-qualification, or execution authority.

### Missing/duplicate current-context hostiles
Before final handoff:
- no current raw receipt -> every routed option resolves `DEFER_UNKNOWN`;
- duplicate current raw receipts -> every routed option resolves `DEFER_UNKNOWN`;
- the rehearsal bridge returns no proposal rather than choosing first/default/previous bucket.

### Zero-row handoff
Final evaluation runs one episode in each latent external mode.

For each step:
1. one current raw receipt is recorded;
2. `nominate_current_raw_projection_conditioned_rehearsal(...)` internally derives one consistent current bucket across all eligible options;
3. rehearsal receives **zero supplied transition rows**;
4. no preferred action, projection bucket, or routed relation is caller-supplied;
5. the existing rehearsal owner selects the only currently useful represented step;
6. the ordinary EFFECT execution/outcome path remains unchanged.

Results:

- replacement context: `K-17 -> M-23 -> R-41`, terminal `v`, final value 0;
