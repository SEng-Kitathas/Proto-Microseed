## Question
If `T1` is already represented/current as a lawful EFFECT capability but has no current predictive model, can existing epistemic-deficit / probe / bounded-action machinery lawfully generate a one-step evidence-gathering probe of T1 without supplied transition rows, curiosity reward, semantic token meaning, or consumer-choice policy?

- `REPRESENTED_ALTERNATIVE != PROBE_AUTHORITY`;
- `UNKNOWN_SIGNAL_EFFECT != PERMISSION_TO_EXECUTE`;
- `DEVELOPMENTAL_PRESSURE != EFFECT_AUTHORITY`;
- `EPISTEMIC_PROBE != TOKEN_MEANING`;
- `PROBE_RESULT != CONVENTION_IDENTITY`;
- `PROBE_AVAILABLE != AUTOMATIC_EXECUTION`;
- `INFORMATION_VALUE != REGULATORY_VALUE`.

## Composition audit
Existing owners were inspected before experiment:
1. `record_action_limited_unknown(...)` persists a bounded UNKNOWN but requires caller-supplied `hypothesis_digest_sha256` and `missing_discriminator_signature_sha256`;
2. `bind_probe_capability(...)` checks current qualification/epoch but accepts the capability id named by the caller and transitions the deficit to `PROBE_AVAILABLE`;
3. modern `derive_current_program_discriminator_satisfaction(...)` requires a current registered discriminator contrast and exact current source-relation ancestry;
4. `current_revised_surface_direct_probe_availability(...)` identifies candidate probes only downstream of an already represented revised contrast built from qualified predicted branch relations;
5. epistemic step intent still requires the modern discriminator-satisfaction, feasibility, route/currentness, priority and information gates before intent, and ordinary EFFECT authority before execution.

This architecture predicts a boundary: legacy probe binding can carry externally supplied probe identity, while modern content-grounded probe authority cannot originate an unmodeled action whose outcome partition is not yet represented.

`LEGACY_PROBE_BOUND != PROBE_RELEVANCE_DERIVED`.

`CALLER_SELECTED_CURRENT_CAPABILITY + DEFICIT != CONTENT_BOUND_PROBE_JUSTIFICATION`.
