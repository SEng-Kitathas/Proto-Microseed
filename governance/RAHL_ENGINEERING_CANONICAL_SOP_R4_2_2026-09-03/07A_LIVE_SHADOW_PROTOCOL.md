# 07A — Live Shadow Protocol

Purpose: preserve the smallest artifact that still carries current operational truth.

## Required fields
1. Thread / project identity and last update.
2. Active intent.
3. Current authoritative state.
4. Active constraints.
5. Decisions locked in.
6. Open loops.
7. Immediate next step.
8. Bounded recent-turn reinforcement where conversational work is involved.
9. Delta since previous shadow.

## Maintenance
Before substantive work when the shadow exists:
1. re-read it;
2. reconcile it with the current request and recent exchanges;
3. update it when load-bearing state changes.

The Live Shadow SHALL remain small enough to reread frequently and rich enough to preserve active truth. It SHALL NOT become a transcript, research paper, doctrine archive, or graveyard of superseded details.

If forced to choose, preserve: current intent -> active constraints -> locked decisions -> open blockers -> immediate next action.
