# 03 — Project / Contract Obligation Interface

This SOP is universal only as a process default. It is inert with respect to domain-specific requirements until the actual project, operator, protocol, safety boundary, release contract, compatibility contract, budget, SLO, legal/custody rule, physical environment, or other governing source supplies an obligation.

For every active project-local obligation record:
- scope;
- owner / authority source;
- consequence if violated;
- evidence/currentness requirement;
- status;
- conflict or waiver owner where applicable.

Project-local instructions MAY tighten, specialize, or replace defaults when they possess the authority to do so. They SHALL NOT silently weaken higher-order standing obligations.

`PROJECT_LOCAL_OBLIGATION != UNIVERSAL_ENGINEERING_LAW`
`EXAMPLE != ACTIVE_REQUIREMENT`
`LOCAL_OVERRIDE != AUTHORITY_TO_BREAK_HIGHER_ORDER_CONSTRAINT`
