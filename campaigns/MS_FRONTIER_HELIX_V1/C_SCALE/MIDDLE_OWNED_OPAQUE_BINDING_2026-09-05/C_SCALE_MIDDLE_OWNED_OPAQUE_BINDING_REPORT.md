# C_SCALE — Middle-Owned Opaque Request Binding — 2026-09-05

## Mechanism
03A still contained an evaluator-owned table in the middle boundary: a top request token was translated into a chosen middle context before the middle acted. 03B removes that table.

The top's request token is now carried **unchanged** into the middle's raw observation. It arrives as an opaque signal coordinate beside the middle's own local child-state coordinate. The middle starts with no learned request/effect relations and no signal-conditioned routing. Through its own actions and actual outcomes, it learns which subordinate response works for each opaque-signal/local-state class, detects later drift, qualifies replacement relations, discovers the two-coordinate projection, and qualifies current routing.

After that learned binding exists, the top is still initially unqualified. The top then develops its own policy through actual nested outcomes exactly as in 03A. Leaf-local means remain below the middle boundary.

## Example
Imagine the top can emit two arbitrary marks, `X` and `Y`. The middle does not receive a dictionary saying `X -> context A` and `Y -> context B`. It simply observes whichever mark arrived plus its own local state and tries available subordinate requests. Outcomes teach it which response works.

If the convention is reversed before learning, the middle learns the reversed relation. If an unseen mark arrives, it has no current proposal. Nothing in the experiment assigns semantic meaning to `X` or `Y`.
