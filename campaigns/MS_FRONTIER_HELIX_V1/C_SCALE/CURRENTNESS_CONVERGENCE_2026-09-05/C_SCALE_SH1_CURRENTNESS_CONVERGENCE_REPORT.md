# C_SCALE / SH1 Currentness Convergence — 2026-09-05

## Mechanism
C_SCALE and SH1 are not two competing hierarchy mechanisms. C_SCALE establishes one bounded three-level execution composition from two already-qualified two-level request/effect controllers. SH1, already present in that replay branch's ancestry, uses the same top/middle composition and pressures what happens when the middle changes.

The important rule is local evidence ownership. A hidden middle change does not directly rewrite the top controller's currentness. The middle may change internally while the top relation remains current because the top has not yet observed anything at its own boundary. When actual nested outcomes later contradict the old relation, the middle and top can each earn their own drift witnesses from those real events. If the hidden middle change preserves the observed effect, both layers remain current. If the middle's own dependency becomes explicitly stale, the middle blocks itself immediately; the top becomes stale only after its own repeated refused/failed nested outcomes provide evidence.

## Example
Suppose the top asks the middle for a bounded request class and the middle previously produced a good leaf effect. The middle's hidden phenotype flips so that the same request now produces the opposite effect. Before the top actually uses the path again, the top has no lawful evidence that anything changed. After repeated post-drift nested executions return the bad effect, both the middle and the top can measure failure at their own boundaries and stale the corresponding predictive relations.

If the middle changes internally but still produces the same externally observed effect, neither layer should stale merely because the hidden implementation changed.

**Evidence-local cross-level currentness in a bounded three-level request/effect composition.**

## Application
The C_SCALE frontier does not need a new cross-level currentness manager. The canonical substrate already contains the needed currentness behavior. The stale C_SCALE replay seam is therefore closed by convergence, not by adding production code.

What remains scientifically open in the C line is narrower: can this bounded three-level organization be **grown/learned end-to-end** rather than composed from two controllers that were already independently qualified, and can that be done without smuggling the hierarchy through evaluator-owned mappings or a manager?
