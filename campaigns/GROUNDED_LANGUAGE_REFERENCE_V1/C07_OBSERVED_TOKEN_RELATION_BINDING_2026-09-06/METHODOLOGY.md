# C07 Methodology — Opaque Observed Token / Relation Binding

## Mechanism
C06 earns two possible ordered operational relation surfaces from lived external outcomes. C07 adds an opaque token only as observation evidence. The token is not an action and is not given a predicate meaning.

The decisive control is **two opposing relation classes**. One token repeatedly accompanies one C06 order and a second token repeatedly accompanies the opposite order. A disjoint holdout must reproduce the same bijection. This prevents one-token co-occurrence from passing as grounding.

The token value is written into Microseed's append-only evidence ledger and read back from that ledger before association. The final derived binding set is also content-bound evidence and is read back during resolution.

## Example
If opaque surface `K7` repeatedly accompanies operational order `[r1,r2]`, while `M2` repeatedly accompanies `[r2,r1]`, and an independent holdout repeats the same pairing, the evidence supports a bounded token/relation association. Swapping the literal token spellings swaps which surface is learned; spelling itself has no privilege.

## Technical name
**Paired-experience grounding of opaque observed tokens to current affordance-relative relations.**

## Application
This is not yet an organism-native predicate record. It establishes a narrower bridge: opaque observed surfaces can participate in durable content-bound evidence that distinguishes opposing grounded relation orders without installing a language faculty or executable relation action.

## Ceiling
Pairing episode boundaries and qualification remain research-harness supplied. The derived binding is durable evidence, not yet a native relation object with its own organism-owned currentness index. That is the C08 seam.
