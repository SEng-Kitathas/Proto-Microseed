# C06 Methodology — Affordance-Relative Grounded Order from External Outcome Evidence

## Mechanism
C05 grounded a symmetric binary coeffect by observing an installed relation signal that touched two current referents. C06 asks for directionality under a stronger constraint: **do not install the directional relation as an organism action or capability**.

Two current B1 operational referents already exist. The environment then changes them asymmetrically without Microseed invoking a new relation action. For each referent, C06 derives a local effect basis from the referent's already-grounded low-level action/effect structure. The external change is classified as either aligned with or opposed to that local effect basis. Repeated disjoint evidence must agree on the same order.

The resulting relation handle is generated after evidence. It does not exist before the evidence as a faculty, predicate, semantic class, or executable action.

## Example
Suppose two already-grounded operational referents are affected by a world event. Relative to each referent's own known local-effect basis, one change runs opposite and the other runs aligned. If this same ordered pattern repeats across different raw layouts and an independent holdout, the evidence supports an ordered pair `[opposed, aligned]`.

No label says "giver", "receiver", "subject", "object", "agent", or "patient". Those interpretations are not part of the mechanism.

## Technical name
**Affordance-relative grounded order relation from external outcome evidence.**

## Application
This is a bounded step from symmetric grounded relation toward directionality. It is still not a semantic predicate or proposition. Before propositional composition, the next seam is whether an **observed opaque token** can become grounded to the already-derived current relation without turning that token into an executable relation action or preinstalled language faculty.

## Currentness
The derived relation is not timeless. Fresh post-binding event evidence must preserve the same order. A reversed world relation fails closed, including after restart. Restart re-entry requires current B1 referents plus fresh relation evidence.

## Representation hostile
Absolute raw sensor sign is not used as the final order owner. C06 compares external-event effect to each referent's already-grounded local effect basis. Full sensor-polarity inversion changes raw signs but preserves the derived operational order in the tested path.
