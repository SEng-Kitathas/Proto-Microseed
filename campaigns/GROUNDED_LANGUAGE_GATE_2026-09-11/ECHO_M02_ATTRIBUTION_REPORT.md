# Echo-M02 Attribution — Grounded Counterpart Call-Name Preference

## Origin
The user explicitly told Veya: `you can call me Rahl`. Echo-M01 preserved this as a historical utterance event, but that alone did not authorize Veya to treat `Rahl` as the user's conversational name. M02 tests that narrower relation.

## Earned focused mechanism
M02 derives a current call-name preference only from an exact owned M01 episode containing an explicit, unambiguous preference form such as `you can call me X`, `call me X`, or `I prefer to be called X`. Hedged, negated, or ambiguous forms abstain.

The preference is tied to the opaque counterpart ID + epoch. A later explicit preference becomes current while earlier preference evidence remains in history. Wrong counterpart and changed counterpart epoch do not reuse the current preference.

## Epistemic ceiling
`CALL_NAME_PREFERENCE != HUMAN_IDENTITY_TRUTH`. `Rahl` means only: under this opaque counterpart coordinate, the counterpart explicitly asked to be called Rahl. It is not legal-name truth, real-world identity proof, social-relationship authority, or profile truth.
