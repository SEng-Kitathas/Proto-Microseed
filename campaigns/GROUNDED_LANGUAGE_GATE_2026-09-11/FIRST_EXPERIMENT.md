# First Experiment — Grounded Referent Readout With Opaque-Carrier Control

## Question
Can an already-grounded operational referent relation be exposed through a readable token without the readable token becoming the source of referent competence?

## Positive arm
Use an already-owned grounded token→referent candidate and permit a readable surface label solely as a report/coordination output.

## Required matched controls
- same grounded state with opaque token IDs;
- surface-token permutation with grounding preserved;
- language-disabled task execution where communication output is not required;
- fluent but ungrounded labels;
- alias/paraphrase variants bound to the same referent.

## Success criterion
Readable language may improve interpretability or counterparty coordination, but underlying referent selection/currentness/ambiguity behavior must track grounding and remain available under opaque controls.

## Freeze criterion
If readable wording itself supplies referent choice, truth, plan, permission, or noncommunicative task competence beyond the grounded/opaque control, freeze the branch.

## Nonclaims
No semantics system, grammar, syntax, proposition truth, planner authority, LLM integration, generic symbol grounding, or canon promotion.
