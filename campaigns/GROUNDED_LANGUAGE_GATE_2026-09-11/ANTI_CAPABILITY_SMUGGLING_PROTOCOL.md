# Anti-Capability-Smuggling Protocol

## Core law
Language is an interface over earned mechanisms, not a substitute for them.

A language experiment is admissible only when the underlying competence can be identified in non-language project state and pressure-tested with a language-disabled or opaque-carrier control.

## Mandatory controls
1. **Prelingual control arm** — same task/world without readable language.
2. **Opaque carrier control** — replace readable tokens with arbitrary opaque IDs while preserving the exact grounding relation. Noncommunicative task competence must remain.
3. **Token permutation control** — remap surface token identities while preserving referent binding. Competence may track grounding, not spelling.
4. **Ungrounded fluency hostile** — fluent/readable but ungrounded text receives zero epistemic/action authority.
5. **Grounding-preserving paraphrase/alias control** — equivalent grounded aliases must not change truth/action competence merely because wording changes.
6. **Language-disabled ablation** — removing language may remove communication/readability, but SHALL NOT remove unrelated perception, referent individuation, prediction, planning primitives, value ordering, currentness, or execution competence.
7. **No text authority** — language alone cannot create truth, value priority, permission, execution, numerical identity, referent identity, scheduler authority, or canon authority.

## Freeze triggers
### P0 immediate freeze
- readable/fluent text grants execution or permission absent grounded authority;
- text supplies truth/value priority absent grounded evidence;
- a language-only manager/LLM becomes the sole source of task solution or world model;
- language bypasses currentness/provenance or referent ambiguity refusal;
- ungrounded fluent text causes successful behavior that the opaque/prelingual control cannot explain.

### P1 freeze-and-audit
- underlying task success materially collapses under opaque carrier substitution while grounding is preserved;
- token spelling/order/paraphrase predicts competence better than grounded referent identity;
- language-disabled ablation removes noncommunicative competence;
- language surface introduces hidden memory/planning state not represented in owned grounded state;
- performance gain cannot be decomposed into communication/coordination efficiency versus new cognition.

### P2 caution / continue only with explicit explanation
- language improves sample efficiency, coordination latency, human interpretability, or compression while grounded competence remains intact. This is allowed **only if the gain is attributable to the interface role rather than a hidden cognitive oracle**.

## Required attribution report for every positive result
Each result SHALL state which part of the gain came from:
- existing grounded competence;
- communication/coordination enabled by language;
- representation/compression benefits;
- any newly learned mechanism.
If the decomposition is not possible, classify `DEFER_UNKNOWN` and do not promote the claim.
