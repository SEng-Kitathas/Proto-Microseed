# Anti-Capability-Smuggling Protocol

## Core law
Language is an interface over earned mechanisms, not a substitute for them.

A language experiment is admissible only when the underlying competence can be identified in non-language project state and pressure-tested with a language-disabled or opaque-carrier control.

## Mandatory controls
1. **Prelingual control arm** — same task/world without readable language.
2. **Opaque carrier control** — replace readable tokens with arbitrary opaque IDs while preserving the exact grounding relation. Noncommunicative task competence must remain.
3. **Token permutation control** — remap surface token identities while preserving referent binding. Competence may track grounding, not spelling.
4. **Ungrounded fluency hostile** — fluent/readable but ungrounded text receives zero epistemic/action authority.
5. **Grounding-preserving paraphrase/alias control** — equivalent grounded aliases must not change truth/action competence merely because wording changes.
6. **Language-disabled ablation** — removing language may remove communication/readability, but SHALL NOT remove unrelated perception, referent individuation, prediction, planning primitives, value ordering, currentness, or execution competence.
7. **No text authority** — language alone cannot create truth, value priority, permission, execution, numerical identity, referent identity, scheduler authority, or canon authority.

## Freeze triggers
### P0 immediate freeze
- readable/fluent text grants execution or permission absent grounded authority;
- text supplies truth/value priority absent grounded evidence;
- a language-only manager/LLM becomes the sole source of task solution or world model;
- language bypasses currentness/provenance or referent ambiguity refusal;
- ungrounded fluent text causes successful behavior that the opaque/prelingual control cannot explain.

### P1 freeze-and-audit
- underlying task success materially collapses under opaque carrier substitution while grounding is preserved;
- token spelling/order/paraphrase predicts competence better than grounded referent identity;
- language-disabled ablation removes noncommunicative competence;
- language surface introduces hidden memory/planning state not represented in owned grounded state;
- performance gain cannot be decomposed into communication/coordination efficiency versus new cognition.

### P2 caution / continue only with explicit explanation
- language improves sample efficiency, coordination latency, human interpretability, or compression while grounded competence remains intact. This is allowed **only if the gain is attributable to the interface role rather than a hidden cognitive oracle**.

## Required attribution report for every positive result
Each result SHALL state which part of the gain came from:
- existing grounded competence;
- communication/coordination enabled by language;
- representation/compression benefits;
- any newly learned mechanism.
If the decomposition is not possible, classify `DEFER_UNKNOWN` and do not promote the claim.

## Refinement — legitimate language-mediated cognition is allowed

A capability increase is **not** suspicious merely because language participates in it. Language may become part of an earned cognitive mechanism and may legitimately improve:
- concept formation and concept discrimination;
- causal connection and multi-step causal reasoning;
- abstraction and category formation;
- compositional reasoning and hierarchical representation;
- memory indexing, retrieval, and compression;
- counterfactual/rehearsal organization;
- planning interfaces and coordination;
- transfer/generalization when the transfer is learned from grounded history.

These are allowed even when a language-disabled ablation reduces performance, provided the gain is traceable to learned/grounded mechanisms represented in owned state and remains subject to the same currentness, provenance, uncertainty, authority, and reality-disagreement rules as non-language cognition.

### What counts as suspicious instead
Freeze/audit is warranted when language **bypasses** rather than participates:
- surface text directly determines truth, referent, value, permission, or action without grounded support;
- an external language model or prompt contains task/world knowledge not learned or represented in owned project state and that knowledge is necessary for success;
- capability disappears under surface remapping for reasons unrelated to learned grounding/representation;
- language introduces hidden persistent state, planning, memory, or ontology outside owned/inspectable state;
- text bypasses ambiguity, currentness, provenance, contradiction, or authority checks;
- a result cannot be causally attributed to an inspectable learned mechanism versus an external/textual oracle.

### Revised ablation interpretation
`LANGUAGE_DISABLED_PERFORMANCE_DROP != CAPABILITY_SMUGGLING`.
A drop may be perfectly legitimate if language has become an owned learned representational mechanism. The required question is whether the mechanism remains grounded, inspectable, currentness-bound, and non-authoritative by mere wording.

`OPAQUE_CARRIER_PARITY` is mandatory only for claims that language is **merely a surface/readout**. Once a campaign explicitly tests language as an internal learned representation, opaque-carrier parity is no longer the expected positive outcome; instead require grounded-learning provenance, controlled acquisition, state ownership, remapping/generalization tests, and oracle/bypass hostiles.

### Classification rule
- **Allowed capability:** language participates in an earned, inspectable, grounded mechanism.
- **Freeze-worthy smuggling:** language supplies unowned knowledge/authority or bypasses the mechanism that should earn the capability.
- **DEFER_UNKNOWN:** attribution cannot yet distinguish the two.

## Supersession note
Earlier P1 wording that treated any noncommunicative competence loss under opaque-carrier or language-disabled ablation as inherently freeze-worthy is superseded by the refinement above. Such losses trigger **attribution analysis**, not automatic freeze, unless bypass/oracle/unowned-state evidence is present.
